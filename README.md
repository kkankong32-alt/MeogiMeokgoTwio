# 먹이 먹고 튀어 · 1.0.1

개구리와 메뚜기의 입장을 번갈아 맡아 먹이를 먹고, 예고된 천적 공격을 피하고, 목적지에 도착하는 여섯 단계 액션 게임입니다. 게임을 진행하거나 다시 도전할 때 문제를 풀 필요가 없습니다. 교사용 생태 활동은 시작 화면·진행 중·결과에서 따로 열 수 있습니다.

## 실행

- 인터넷 없이: `play-offline.html`을 내려받아 데스크톱 Chrome·Edge·Safari 같은 브라우저에서 엽니다. 코드와 그림이 모두 들어 있습니다
- 정적 웹: 이 폴더의 `index.html`, `style.css`, `src/`, `assets/`를 같은 상대 경로로 제공합니다. GitHub Pages 하위 경로에서도 동작하도록 상대 URL만 사용합니다
- 로컬 개발: `npm start` 후 같은 컴퓨터의 `http://localhost:4781`을 엽니다
- 설치, 회원가입, 외부 서버, 학생 이름, 광고, 분석 도구, 공개 순위표가 없습니다

일부 휴대폰 파일 미리보기 앱은 HTML 스크립트를 실행하지 않습니다. 휴대폰에서는 배포된 HTTPS 웹 주소를 사용하는 편이 적합합니다. 실제 Safari·휴대폰 양손 터치와 성능 검증은 별도로 필요합니다.

## 조작

- 이동: 방향키 / WASD, 또는 왼손 조이스틱
- 먹기: J / Z, 또는 오른손 먹기. 메뚜기는 풀 지점에서 0.9초 동안 유지하면 한 입 먹습니다
- 큰 도약: K / X / SPACE, 또는 오른손 큰 도약. 한 번 눌러 한 번 도약합니다
- 일시정지: ESC 또는 상단 버튼
- 화면 회전·앱 전환·창 크기 변경 후에는 자동으로 멈춥니다. 계속하기를 눌러 재개합니다

먹기는 목표 수를 채운 뒤에도 가능하지만 추가 점수는 두 개까지만 줍니다. 목표를 채우면 목적지로 바로 가세요. 가만히 기다리기만 해서는 성공할 수 없습니다.

## 캠페인

1. 첫 한입: 개구리, 메뚜기 4마리, 90초
2. 이번에는 메뚜기: 풀 6입, 120초
3. 어느 먹이를 노릴까: 개구리, 메뚜기·애벌레 중 곤충 6마리, 120초
4. 숨을 곳이 줄었다: 메뚜기, 은신처 두 곳이 줄어든 같은 지도, 풀 6입, 120초
5. 먹이 길이 달라졌다: 개구리, 메뚜기 2마리·애벌레 8마리 중 6마리, 150초
6. 두 생물의 하루: 개구리 3마리/75초 다음 메뚜기 풀 4입/새 75초

각 구간의 첫 유효 포획은 위기 탈출 한 번을 사용하고 안전한 위치로 옮깁니다. 3초 동안 재포획을 막고, 다음 포획은 실패입니다. 실패 뒤 이어 체험은 먹은 수를 보존하며 시간 없이 계속합니다. 마지막 후반 재도전은 전반 기록을 보존합니다.

도약은 지상에서 6초간 회복하며 먹으면 회복이 끝납니다. 착지 후 2.5초 재사용 제한은 남습니다. 버튼은 이 조건을 합친 실제 준비 상태를 보여 줍니다. 승인된 개구리 도약 원본의 1.62초 동작을 유지했습니다. 기획의 0.8–1.0초는 초기 제안값으로, 원본 동작 보존을 우선한 구현 차이입니다.

## 완료와 점수

도움·이어 체험·후반 재도전도 같은 단계 완료와 완주 축하를 받습니다. 모든 단계는 처음부터 선택할 수 있습니다. 여섯 단계 완료가 모두 있어야 캠페인 완주로 표시합니다.

기본 도전 성공 점수는 목표+도착 600, 위기 탈출 미사용 100, 선택 먹이 각50/최대100, 시간0–200점입니다. 빠른 기준은 제한시간의60%이며, 그 뒤 시간 점수는 `floor(200 × 남은 시간 / (제한시간 × 0.4))`입니다. 800점은2별, 900점은3별입니다. 마지막 단계는 기본 조건으로 연속 성공한 두 구간 평균을 버림 처리합니다.

난도 도움·이어 체험·마지막 후반 재도전은 기본 최고점과 점수 별을 갱신하지 않습니다. 큰 버튼·색 외 모양 경고·먹기 유지·장식 감소는 기본 접근성 기능으로 최고점에 영향을 주지 않습니다.

## 소리와 기록

효과음은 이 프로젝트에서 직접 합성했습니다. 먹기·도약·위험 예고·위기 탈출·목표·성공에 짧게 재생합니다. 첫 사용자 클릭 뒤 오디오를 준비하고, 음소거와 음량 조절을 제공합니다. 소리 없이도 경고와 상태를 볼 수 있습니다.

완료·최고점·설정·교사 활동·플레이 기록은 브라우저의 기기 내 저장소에 별도로 저장합니다. 현재 진행 중인 판 전체의 자동 복원은 제공하지 않습니다. 마지막 단계의 전반 완료는 보존하며 재접속 후 후반을 체험 조건으로 시작할 수 있습니다. 저장이 차단되거나 용량을 초과하면 저장 성공으로 표시하지 않습니다. 새 학생용 초기화에는 별도 확인 화면이 있습니다.

## 선택형 교사 활동

제공 교과서38–61쪽, 실험관찰20–35쪽의40쪽 범위에 대응하는12개 활동, 용어 안내, A–F 선택 문항을 담았습니다. 첫 생각과 도움말 후 수정을 분리하며 자동 채점하지 않습니다. 보전 계획과 실제 날짜·행동은 별도로 기록합니다. 모든 게임 사건·이동 경로는 가상 모형의 기록이며 현장 관찰 자료가 아닙니다. 외부 교재 PDF·원문 이미지·개인 보관 파일 주소는 재배포하지 않습니다. 근거는 출판사·교재명·인쇄 쪽수만 제공합니다.

## 개발 검증

개발 검수 환경은 Node24입니다. 최초 한 번 `npm install` 후 `npm run build` → `npm test` → `npm run check`를 실행합니다. 배포된 게임을 플레이할 때는 설치가 필요 없습니다.

게임 런타임과 순수 규칙 테스트는 외부 패키지가 없습니다. DOM 자산 디코딩 검사와 네이티브 그림 검수에는 개발 의존성 `@napi-rs/canvas`0.1.100을 사용합니다. 한글 그림 검수에는 로컬 한글 글꼴을 사용하며 이런 개발 도구와 글꼴을 게임 런타임에 포함하지 않습니다. `qa/campaign-replay.mjs`는 실제 Input API를 통해 이동·먹기·도약을 전달하는 재현 검사입니다. 캐릭터 순간이동·먹이 추가·AI 비활성화 없이 기본·도움 조건의 모든 구간을 완료합니다.

자세한 결과와 미검증 범위는 `QA.md`, 자산 출처는 `ASSETS.md`, 배포 파일 해시는 `release-manifest.json`을 참고하세요. 실제 어린이의 재미·성공률·학습 효과, 실제 휴대폰/Safari/GPU/FPS, 수업시간은 검증했다고 주장하지 않습니다.
